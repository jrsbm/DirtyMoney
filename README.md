# Dirty Money ~ A Food Fraud game

In a world where fraudulent food is prevalent, a trading company attempts to supply the world with only the best authentic foods. However, with supply chains ever growing in size and complexity it is hard to know who to trust. Even the company itself might be compromised...

## Contents

This repository contains the print files and a webapp of the serious game Dirty Money. Dirty Money is an adaptation of the game 'Secret Hitler'. It is an educational, hidden-role, team-based game where players must try to learn the roles of others while trading authetic *or* fraudulent batches of food. The social deduction element of the game is a starting point for discussions about trust in food supply chains. Furthermore, an economy element in the game teaches how food business operators might make different choices under pressure. The printed game can be played by groups of 5 to 8 players.

## Print files

The folder /visuals contains all the necessary imagary and instructions to print the boards and cards of the game. Additionally you will need 8 envelopes and 8 coins (or similar, to indicate monitary value). Board-print pdf's are  sized 480mm x 300mm and formatted in colour profile ICC FOGRA39 (ISO 12647-2:2004). Cards are 'pokersized', 2.5in x 3.5in (63.5 mm x 88.9 mm).
